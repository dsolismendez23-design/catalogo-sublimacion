    Enlace para celulares (iPhone y Android)

    Envíe este enlace a quien vaya a pedir. Se abre en Safari o Chrome y se instala con "Agregar a pantalla de inicio". El catálogo se actualiza solo cada día.

    Archivo para celular Android (sin internet de por medio)

    Genera un solo archivo (CatalogoSublimacion.html) con el catálogo actual. Páselo al celular (por WhatsApp, cable o Drive) y ábralo con Chrome o Safari. Cuando haya diseños nuevos, genérelo otra vez y reemplace el del celular.
